# Asset provenance

`brand-mark.svg` is original code-drawn wallet geometry matching the in-app brand. `web-favicon.png` is a 256px rasterization of that SVG via Sharp, used only as the local browser preview favicon. No AI-generated imagery or remote image fetches are involved.

The `images/` and `expo.icon/` files came from the official Expo SDK 57 default template during scaffolding. They are not referenced by BakiBuddy's app configuration or screens. Final native launcher icon and splash artwork still require release preparation.
