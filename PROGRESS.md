## Architecture and financial decisions

ANALYTICS_RULES.md records the human-readable calculation contract; src/analytics/engine.ts owns executable financial totals. The chart package receives verified integer-sen values solely for display geometry. No chart rounding or coordinate computation changes money.

Historical ranges include both endpoints, whereas budget usage retains Phase 3's [start,end) current-cycle semantics. Comparisons use the immediately preceding equal-day range and the same account. A missing baseline has no defined percentage; missing records do not prove no spending. Average expense divides gross expenses by all calendar days and floors whole sen. Refunds remain separate and do not reset category spending or a cap. Transfers are counted as excluded entries, including in a receiving-account filter. Category percentages use a deterministic largest-remainder allocation to 10,000 basis points.

The current budget section explicitly includes all accounts/current cycle regardless of the history filters. Used/committed cap = gross recorded cycle expenses + unpaid bills; an actual linked bill replaces its pending commitment. Actual overage remains explicit when the graphic stops at 100%.
