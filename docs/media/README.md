# Demo media

All financial records in these images are fictional. The four screenshots were captured on **29 October 2026** from the actual **v0.8.1 React Native Web build**, at 390 × 844, using an isolated local preview origin. Records were entered through ordinary app controls; no data was seeded into the production app or the owner's native ledger. The ledger is not included in the repository.

These are not iPhone/Android screenshots, generated mockups, performance benchmarks or proof of native acceptance. No remote stock photography or AI-generated artwork is used.

## Fictional scenario

- Demo Bank opening balance: **RM1,000.00**.
- Income: Monthly allowance **RM500.00**.
- Expenses: Campus lunch **RM12.50**, Weekly groceries **RM68.40**, Rapid KL trip **RM7.50**.
- Recorded balance: **RM1,411.60**; gross expenses: **RM88.40**.
- Weekly plan: 29 October–5 November 2026, seven included days.
- Savings reserve: **RM200.00**; one unpaid Demo bill: **RM100.00**.
- Available for extra spending: **RM1,111.60**; daily allowance: **RM158.80**.

The application computes these displayed values. The unpaid schedule is separate from the four saved transactions. All four records use 29 October 2026; there are no refunds or transfers in this particular screenshot scenario. Domain tests separately cover those transaction kinds.

The wallet mark is original project geometry. Manrope and platform fonts match the app's established system; external template artwork is not used in the gallery.
